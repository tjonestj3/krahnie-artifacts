# Morning AI TL;DR — 2026-05-20

- **Google I/O shifted the agent race up a gear:** Google announced **Gemini 3.5** for complex agentic workflows plus **Gemini Omni** for multimodal creation/editing, making Google’s stack more directly competitive for builders standardizing on action-oriented models ([Google I/O 2026 collection](https://blog.google/innovation-and-ai/technology/developers-tools/google-io-2026-collection/)).
- **Gemini 3.5 Flash is positioned as the fast/default builder model:** Google says 3.5 Flash outperforms Gemini 3.1 Pro on most benchmarks while running much faster, with API, AI Studio, Vertex AI and Antigravity access—worth testing for coding agents and high-volume workflows ([Google developer highlights](https://blog.google/innovation-and-ai/technology/developers-tools/google-io-2026-developer-highlights/)).
- **Antigravity 2.0 becomes a broader agent dev platform:** I/O coverage points to a desktop app, CLI, SDK, managed execution/API and enterprise support, signaling Google wants agent-building to be an end-to-end platform rather than just IDE autocomplete ([Developers Google Blog](https://developers.googleblog.com/all-the-news-from-the-google-io-2026-developer-keynote/); [9to5Google](https://9to5google.com/2026/05/19/google-antigravity-agentic-developer-suite/)).
- **Google added managed agents to Gemini API:** Developers can run Antigravity agents in secure cloud sandboxes and define custom agents with versionable `AGENTS.md` / `SKILL.md`, a pattern that maps well to repeatable enterprise automation ([Google managed agents](https://blog.google/innovation-and-ai/technology/developers-tools/managed-agents-gemini-api/)).
- **Anthropic acquired Stainless:** Stainless generates and maintains production SDKs/MCP tooling for APIs; Anthropic frames the buy as infrastructure for agents that need reliable access to external systems ([Anthropic](https://www.anthropic.com/news/anthropic-acquires-stainless); [TechCrunch](https://techcrunch.com/2026/05/18/anthropic-has-acquired-the-dev-tools-startup-used-by-openai-google-and-cloudflare/)).
- **GitHub’s JetBrains Copilot update adds more agent surface area:** Copilot for JetBrains gained a CLI agent and unified sessions view, another sign that coding agents are converging across terminal, IDE and background task flows ([GitHub Changelog](https://github.blog/changelog/2026-05-13-introducing-copilot-cli-agent-and-unified-sessions-view-in-github-copilot-for-jetbrains-ides/)).
- **Salesforce Summer ’26 remains relevant for ecosystem builders:** Salesforce is pushing multi-agent orchestration in Agentforce, Slack-first workflows and real-time Data 360 activation—less “new today,” but important for planning agentic CRM architectures ([Salesforce](https://www.salesforce.com/news/stories/summer-2026-product-release-announcement/)).

**Worth watching:** The practical near-term win is not “fully autonomous agents,” but standardized agent packaging—`AGENTS.md`, MCP/SDK generation, managed sandboxes and enterprise orchestration are becoming the integration layer to build around.
