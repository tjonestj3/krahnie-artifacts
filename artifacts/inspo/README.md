# Inspiration Lab

This folder keeps recurring inspiration artifacts out of the general `reports/` bucket as the Krahnie arcade grows.

Suggested structure:

```text
artifacts/inspo/
  game-dev/
    indie-pvp-retro-inspo/   # daily PvP / mage duel / arena battler prototype visions
  ai/
  salesforce/
  creative/
```

Rule of thumb: put artifacts here when they are idea fuel, reference boards, prototype visions, or design scouting. Put polished explainers/showpieces under `artifacts/html-sites/`, and runnable exports under `artifacts/prototypes/`.
